
### **Run the book management application**

Open a terminal and run the folowiing comand:

    cd bookmanagementservice && ./start.sh

The Swagger API Documentation can be found at the following address:
[http://localhost:8085/swagger-ui.html](http://localhost:8085/swagger-ui.html#/book-controller)

### **Run the webservice application**	
Open a new terminal and run the following command:

    cd webservice && ./start.sh	

Access the web service page at this address:
[http://localhost:8081/books](http://localhost:8081/books/create)
