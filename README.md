
### **Run the book management application**

Open a terminal and paste the folowiing comand:

    cd bookmanagementservice && ./start.sh

### **Run the webservice application**	
Open a new terminal and execute the following command below:

    cd webservice && ./start.sh	

Open your browser to access the web service page at this address:
[http://localhost:8081/books](http://localhost:8081/books/create)
